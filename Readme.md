# Симуляция роботов-тележек в производственном цеху

Веб-приложение для симуляции работы роботов-тележек в производственном цеху.

## Возможности

- Расстановка оборудования в цеху (роботы, конвейеры, посты, склады)
- Настройка параметров движения и времени
- Многослойная симуляция с возможностью совмещения
- Автоматическая маршрутизация
- Статистика работы

## Структура проекта

- `index.php` - главная страница
- `config.php` - конфигурация
- `simulation.js` - основная логика симуляции
- `style.css` - стили
- `save_config.php` - сохранение конфигурации

## Запуск

Просто откройте `index.php` в веб-браузере с поддержкой PHP.
